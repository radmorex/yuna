# Параметры оверлея

Добавляются к адресу `overlay.html` (Browser Source в OBS: 1920×1080), можно комбинировать:
`overlay.html?scale=0.8&x=40&y=40&side=right`

| Параметр | Пример | Что делает |
|---|---|---|
| `scale` | `scale=0.8` | Масштаб всего блока (0.25–2). Якорь — нижний угол блока. |
| `x`, `y` | `x=40&y=40` | Отступ блока от левого (или правого при `side=right`) и нижнего края, px. По умолчанию 36/36. |
| `side` | `side=right` | Блок в правом нижнем углу; чат остаётся слева от аватара, Юна — у края экрана. |
| `chat` | `chat=0` | Только аватар с плашкой «ЮНА · соведущая», без шапки и чата (для отдельной сцены). |
| `bg` | `bg=1` | Тёмный тестовый фон (для скриншотов; в OBS не нужен — фон прозрачный). |
| `demo` | `demo=1` | Локальный фейковый чат без сервера. |
| `avatar`, `model` | `avatar=vrm&model=/models/mira.vrm` | VRM-модель вместо SVG (см. `models/README.md`), при ошибке — откат на SVG. |
