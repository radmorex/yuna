# VRM-модели для Юны

Положите сюда файл модели (VRM 0.x или 1.0), например `mira.vrm`, и откройте оверлей так:

    overlay.html?avatar=vrm&model=/models/mira.vrm

- Если модель или библиотеки (three@0.169.0, @pixiv/three-vrm@3.1.0 c cdn.jsdelivr.net) не загрузились —
  оверлей остаётся на SVG-аватаре, причина пишется в консоль (`[mira] VRM avatar failed…`).
- Эмоции → VRM-выражения: neutral → нет, smug → relaxed + немного happy, surprised → surprised,
  angry → angry, laugh → happy. Рот: `aa`/`oh`, моргание: `blink`.
- Наряды: узлы сцены, в имени которых есть `hoodie` / `dress`, включаются/выключаются.
  Если таких узлов нет — смена наряда игнорируется, показывается тост.
- Модели — чужая интеллектуальная собственность: кладите только те, лицензия которых разрешает стрим.
  Файлы `*.vrm` в git не коммитим.
