# Юна

Особиста голосова ШІ-асистентка для робочого столу macOS. Ядро написане на Rust, розпізнавання голосу, слово-активатор і вікно на Python. Юна розуміє українську, відповідає коротко, а дії на комп'ютері виконує код, тому модель не може вигадати результат.

> Приватний проєкт. Доступ лише за запрошенням, умови в [LICENSE](LICENSE).

## Безпека: доступ до комп'ютера усталено вимкнений

Після встановлення Юна не керує комп'ютером і не слухає мікрофон. Вона може лише говорити, шукати в мережі, показувати погоду й ставити таймер.

Щоб увімкнути доступ, додай у `.env`:

```bash
PC_CONTROL=true
```

Це дає Юні право відкривати й закривати програми, керувати музикою, гучністю й VPN, надсилати повідомлення від твого імені, робити знімок екрана, слухати мікрофон і звук системи. Вмикай це лише на своєму Mac і лише якщо розумієш ризик. Помилково розпізнана команда може надіслати повідомлення людям.

Голосове повідомлення надсилається лише після твого «так». Текстова команда надсилає його одразу.

## Що потрібно

- macOS на Apple Silicon. Керування комп'ютером працює тільки на macOS.
- [Rust](https://rustup.rs), [uv](https://docs.astral.sh/uv/), Python 3.12, `ffmpeg`, Node.js для команд `npm run`.
- Ключ будь-якої OpenAI-сумісної моделі, або локальна [Ollama](https://ollama.com). Для демо ключ не потрібен.

## Запуск

Демо без ключів:

```bash
cp .env.example .env
npm run demo
```

Асистентка на робочому столі:

```bash
cp .env.example .env
# у .env задай LLM_PROVIDER, OPENAI_API_KEY, OPENAI_MODEL, OPENAI_BASE_URL
npm run desktop
```

Сервер слухає лише `127.0.0.1:8787`. Ключі зберігаються тільки в `.env`, цей файл не потрапляє в git. Ніколи не коміть його.

## Що вміє

| Сказати Юні | Що буде | Потрібно `PC_CONTROL=true` |
|---|---|---|
| `погода у Києві`, `таймер на 10 хвилин` | погода, таймер | ні |
| `знайди рецепт борщу`, `dns example.com` | пошук, дані про домен | ні, але потрібні зовнішні інструменти, див. нижче |
| `що ти вмієш` | список команд | ні |
| `відкрий ютуб`, `закрий Safari` | сайт або програма | так |
| `увімкни музику`, `наступний трек`, `запусти мій плейлист` | Spotify | так |
| `запусти відео про космос`, `постав ютуб на паузу` | YouTube | так |
| `гучність 30`, `нагадай через 10 хвилин подзвонити` | гучність, нагадування | так |
| `що на екрані` | знімок екрана йде в модель лише за цією командою | так |
| `перевір впн`, `увімкни впн` | Mullvad VPN | так |
| `напиши @nick привіт`, `напиши щось @nick` | повідомлення через Forkgram | так |
| `подзвони Саші`, `зайди в войс друзі` | дзвінок, голосовий канал Discord | так |

Кнопка «Юна» вмикає слово-активатор, як у Siri. Режим «Інкогніто» працює лише з підтвердженим Mullvad VPN і розпізнає голос локально.

## Чого в цьому репозиторії немає

- **Ключів і особистих даних:** контактів, плейлистів, пам'яті. Вони створюються локально в `.env` і `data/`.
- **Голосових моделей:** папка `voices/` не входить у репозиторій, бо кожна модель має власну ліцензію.
- **Зовнішніх інструментів пошуку:** `tools/arsenal.py` викликає окремі пакети `osint-kit` і `public-tools`. Шляхи задають `OSINT_KIT_DIR`, `PUBLIC_TOOLS_DIR` і `ARSENAL_PYTHON`. Без цих пакетів такі команди чесно повідомлять про помилку, а решта працюватиме.

## Як влаштовано

| Папка | Що всередині |
|---|---|
| `core/` | Rust-ядро: розбір команд і навички (`skills.rs`), конвеєр (`pipeline.rs`), мозок і фільтри (`brain/`), голос (`tts/`), HTTP-сервер (`server.rs`) |
| `tools/` | Python: слово-активатор, розпізнавання голосу, вікно, інструменти |
| `public/` | Панель, аватар, сторінки керування |
| `discord_bot/` | Необов'язковий міст до Discord |
| `tests_py/` | Python-тести, тести Rust лежать у модулях `core/src` |
| `scripts/` | Скрипти запуску й тестів |

У коді лишився старіший режим співведучої для Twitch, Discord і OBS (`npm start`). Його налаштування описані в `.env.example`.

## Відомі обмеження

- Команди розбираються правилами, тому незвичне формулювання може не спрацювати.
- Керування залежить від AppleScript і натискань клавіш, тому може зламатися після оновлення програм.
- Живий голос, дзвінки, Discord і надсилання кільком людям наживо перевірені не повністю.
